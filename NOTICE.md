## Upstream baseline: Meridian FX

This repository started from an imported upstream project, **Meridian FX** by **Team Ippo**, built for ETHGlobal Cannes
2026 (Base, Arc, Uniswap, Chainlink CRE, World ID, Unlink). The upstream README states an MIT licence; no separate
LICENSE file was present in the imported tree. The imported, unmodified state is tagged `pre-hackathon`
(commit `75e48c2`). The monorepo scaffold, the application and oracle skeletons, and the timing-score / adaptive-TWAP
strategy concept come from that baseline and were adapted for NEAR; all EVM code was removed. See `docs/AUDIT.md` and the
"Hackathon disclosures" section of `README.md`. Upstream copyright notices are retained.
